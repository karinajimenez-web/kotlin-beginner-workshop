## Contenido

- `exercise-01/Exercise01.kt`: calculadora básica con `when` y control de división por cero.
- `exercise-02/Exercise02.kt`: promedio y clasificación de calificaciones.
- `exercise-03/Exercise03.kt`: tabla de multiplicar y suma de resultados.
- `exercise-04/Exercise04.kt`: análisis de una lista de números enteros.
- `exercise-05/Exercise05.kt`: funciones para números primos, factorial y paridad.
- `exercise-06/Exercise06.kt`: clase `Product` y cálculo del valor del inventario.
- `exercise-07/Exercise07.kt`: agenda de contactos con agregar, listar, buscar y eliminar.
- `exercise-08/Exercise08.kt`: saludo usando manejo seguro de valores nulos.

## Cómo ejecutar los ejercicios

1. Instala IntelliJ IDEA con soporte para Kotlin o abre [Kotlin Playground](https://play.kotlinlang.org/).
2. Abre el archivo `Exercise01.kt` del ejercicio que quieras ejecutar.
3. Copia el contenido del archivo en el editor, si estás usando Kotlin Playground.
4. Ejecuta el programa con el botón **Run**.
5. Cada ejercicio es independiente; ejecútalos por separado.

## Nota

Los datos de ejemplo pueden modificarse para probar distintos valores y observar los resultados.
